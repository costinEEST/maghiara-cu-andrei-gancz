Lecția 17, exercițiul 4

Revino la Desinențe de complemente de loc Revino la Sakkozni tudni kell / Șah trebuie să știi să joci

Alegeți desinența potrivită a complementului de loc, în varianta sa corectă.

Exemplu: A hajóra teszik a kocsit. /
    A kocsi a hajón van. /
    Leveszik a kocsit a hajóról. 		Mașina se pune pe vapor. /
    Mașina e pe vapor. /
    Se ia jos mașina de pe vapor. 		[-ul vapor-spre-pe pun-ei -a mașină (acuz.). /
    -a mașină -ul vapor-pe este. /
    În-jos-iau-ei -a mașină (acuz.) -ul vapor-de-pe.]

1.

 A tér megyünk. /
    A tér találkozunk. /
    A tér jövünk. 		Mergem în piață. /
    Ne întâlnim în piață. /
    Venim din piață. 		[-a piață-spre-pe mergem. /
    -a piață-pe întâlnim. /
    -a piață-de-pe venim.]

2.

 A blúzom teszem az ékszert. /
    Az ékszer a blúzom van. /
    Leveszem az ékszert a blúzom. 		Îmi pun bijuteria pe bluză. /
    Bijuteria mi-e pe bluză. /
    Îmi iau bijuteria de pe bluză. 		[-a bluză-mea-spre-pe pun-o -a bijuterie (acuz.). /
    -a bijuterie -a bluză-mea-pe este. /
    În-jos-iau-o -a bijuterie (acuz.) -a bluză-mea-de-pe.]

3.

 A könyv teszem a süteményt. /
    A sütemény a könyv van. /
    Leveszem a süteményt a könyv. 		Pun prăjitura pe carte. /
    Prăjitura e pe carte. /
    Iau prăjitura de pe carte. 		[-a carte-spre-pe pun-o -a prăjitură (acuz.). /
    -a prăjitură -a carte-pe este. /
    În-jos-iau-o -a prăjitură (acuz.) -a carte-de-pe.]

4.

 A vevő a pult néz. /
    A vevő látja a nadrágot a pult. /
    A vevő leveszi a nadrágot a pult. 		Cumpărătorul se uită pe tejghea. /
    Cumpărătorul vede pantalonii pe tejghea. /
    Cumpărătorul ia pantalonii de pe tejghea. 		[-ul cumpărător -a tejghea-spre-pe privește. /
    -ul cumpărător vede-îl -ul pantalon (acuz.) -a tejghea-pe. /
    -ul cumpărător în-jos-ia-îl -ul pantalon (acuz.) -a tejghea-de-pe.]

5.

 Lemegyek az utcá. /
    Az utcá vagyok. /
    Az utcá jövök. 		Cobor pe stradă. /
    Sunt pe stradă. /
    Vin de pe stradă.		 [În-jos-merg-eu -a stradă-spre-pe. /
    -a stradă-pe sunt-eu. /
    -a stradă-de-pe vin-eu.]
