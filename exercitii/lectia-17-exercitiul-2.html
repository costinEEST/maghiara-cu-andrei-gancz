Activitatea 077 — Lecția 017, exercițiul 002

Revino la lecție pentru explicații și exemple. Completează activitatea înainte de a consulta răspunsurile.

Revino la Prefixul verbal Revino la Sakkozni tudni kell / Șah trebuie să știi să joci

Exprimați faptul că acțiunea va fi încheiată, cu ajutorul prefixului le- , aici fără sens local.

1.

 Játszunk egy partit.
→ egy partit. 		Jucăm o partidă. (tocmai o facem)
→ Jucăm o partidă. (până la capăt) 		[Jucăm o partidă (acuz.).
→ În-jos-jucăm o partidă (acuz.).]

2.

 Fényképez egy gyereket.
→ egy gyereket. 		Fotografiază un copil. (tocmai o face)
→ Fotografiază un copil. (va încheia această acțiune) 		[Fotografiază un copil (acuz.).
→ În-jos-fotografiază un copil (acuz.).]

3.

 Rajzolok egy hajót.
→ egy hajót. 		Desenez un vapor. (tocmai o fac)
→ Desenez un vapor. (voi încheia această acțiune) 		[Desenez un vapor (acuz.).
→ În-jos-desenez un vapor (acuz.).]

4.

 Ír egy leckét.
→ egy leckét. 		Scrie o lecție. (tocmai o face)
→ Scrie o lecție. (până la capăt) 		[Scrie o lecție (acuz.).
→ În-jos-scrie o lecție (acuz.).]

Vezi răspunsurile
  1. Lejátszunk
  2. Lefényképez
  3. Lerajzolok
  4. Leír
